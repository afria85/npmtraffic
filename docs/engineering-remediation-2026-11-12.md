The abbreviated install-v1 format returned 2,972,858 bytes for React and 25,726,726 for Next. Both responses omitted publication timestamps. Repository links now use the version-level `/latest` response, capped at 128 KiB. The server keeps the publication history fetch because it supplies timestamps, limits its decoded response to 48 MiB, and reuses the selected records for client imports. If the limit or upstream request fails, the server can serve a labeled stale snapshot. Without a snapshot, it marks the history unavailable. The limits are operational bounds. Peak memory and OOM behavior were not measured.

Automatic chart markers and the release count use valid stable SemVer publications inside the selected UTC window. Build metadata remains stable. The marker import can include prereleases explicitly and shows the cap of 500 matching publications, ordered newest first. Imported event JSON carries the original registry timestamp. The npm `latest` dist-tag identifies the configured version and can differ from the most recently published version. Publication dates provide context for traffic changes.

### Event compatibility and recovery

JSON file input and saved event data are limited to 512 KiB UTF-8 and 1,000 events per package. A label is limited to 240 UTF-16 code units and a URL to 2,048. Dates must round-trip as UTC calendar dates. The existing event types are allowed, strength may be 1, 2, or 3, and links accept HTTP or HTTPS without credentials. Empty optional URLs from older forms are treated as absent. Unknown fields are discarded and prototype-sensitive event keys are rejected.

Share links retain the 1,500-character limit and the legacy base64url format. Gzip output is read incrementally and cancelled over 64 KiB. Invalid UTF-8 or malformed share records fail before any storage write. File import can still retain valid records from a mixed file and reports skipped entries.

Unreadable saved data stays in its original storage key. The event panel shows a recovery notice and can download the original bytes if storage is readable. Edits are blocked while recovery is needed. To recover such a package, export and keep a backup, repair the JSON, clear only its `npmtraffic:events:<package>` browser storage key, and import the repaired file. An unsuccessful save or quota error leaves the prior snapshot intact. Event labels render as text in the table and tooltip. The current SVG marker is geometry and contains no event label. Both chart exports resolve paint variables on DOM attributes before serialization.
